# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities, personal information, prayer requests, credentials, or access tokens in a public GitHub issue.

Report security concerns privately by emailing `neckerluke@gmail.com` with the subject `Rooted website security`. Include the affected page, a concise description, reproduction steps, and potential impact. Do not include real student or prayer-request data in a proof of concept.

## Supported version

The production version deployed from the `main` branch is the supported version. Security fixes should be proposed through a reviewed pull request and verified before deployment.
